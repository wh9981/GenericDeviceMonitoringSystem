# GenericDeviceMonitoringSystem


This repository is a portfolio sample project.

It demonstrates TCP/UDP communication, binary packet parsing,
JSON message handling, simulator design, and dashboard integration.

All proprietary device ICDs, company-specific source code,
credentials, serial numbers, internal IP addresses, and private protocol details
have been removed or replaced with simplified sample specifications.

AIS/ADS-B/ASTERIX-related implementations are based on publicly available
technical specifications and are written for educational and portfolio purposes.

======================================================================================

본 저장소는 포트폴리오용 샘플 프로젝트입니다.

TCP/UDP 통신, 바이너리 패킷 파싱, JSON 메시지 처리,
장비 시뮬레이터 설계, 대시보드 연동 경험을 보여주기 위한 목적으로 작성되었습니다.

회사 내부 코드, 비공개 장비 ICD, 인증 정보, 시리얼 번호,
내부 IP, 실제 운용 환경 정보는 포함하지 않았으며,
장비별 프로토콜은 단순화된 샘플 규격으로 재구성했습니다.

AIS/ADS-B/ASTERIX 관련 구현은 공개적으로 접근 가능한 기술 문서를 기반으로
학습 및 포트폴리오 목적으로 작성되었습니다.
